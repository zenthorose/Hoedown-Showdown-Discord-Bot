Operational collections

Select collections in HoedownInfo, Rounds, or Tickets for a manual snapshot. Each snapshot copies documents and custom indexes into a timestamped collection in the Backups database. Admin/auth data is excluded. Each snapshot adds a collection and uses additional Atlas storage. Backups remain in the same cluster, so they are not disaster-recovery copies; remove old snapshots manually in Atlas when needed.
